Developer Quick Start
Drop into any project or host on GitHub Pages in under 60 seconds.
Complete Developer Documentation & Offline PDF Manual
Read the full API guide online with interactive examples, or download the official printable PDF formatted for your developer desk.
Read Docs Online → Download PDF

1 Direct CDN Link or Download

Paste the CDN links into your project or download the files:

Download serro.css Download serro.js Docs Online → Download PDF Manual
CSS Link • In <head> 
<link rel="stylesheet" href="https://cdn.jsdelivr.net/gh/soundarrajan-a/serro@main/serro.css">
JavaScript • Before </body> 
<script src="https://cdn.jsdelivr.net/gh/soundarrajan-a/serro@main/serro.js"></script>
<script>
  SERRO.init();
</script>

2 Add Attributes

Attach data-serro to any element or headline you want to animate:

<!-- Motion on element --> <div data-serro="blur-up" data-serro-duration="1800"> Card Content </div> <!-- Kinetic Typography --> <h1 data-serro="text-slide-up" data-serro-duration="1800"> Hero Headline </h1>

3 Configure Options

Optional configuration object:

SERRO.init({ once: false, // two-way: repeat when scrolling up & down rootMargin: "-50px 0px -50px 0px" });
