Developer Quick Start
Drop into any project or host on GitHub Pages in under 60 seconds.

1 Direct CDN Link or Download

Paste the CDN link or download the file directly:

Download mos.css Download mos.js
<!-- In <head> --> <link rel="stylesheet" href="https://cdn.jsdelivr.net/gh/soundarrajan-a/mos@main/mos.css"> <!-- Before </body> --> <script src="https://cdn.jsdelivr.net/gh/soundarrajan-a/mos@main/mos.js"></script> <script> MOS.init(); </script>

2 Add Attributes

Attach data-mos to any element or headline you want to animate:

<!-- Motion on element --> <div data-mos="blur-up" data-mos-duration="1800"> Card Content </div> <!-- Kinetic Typography --> <h1 data-mos="text-slide-up" data-mos-duration="1800"> Hero Headline </h1>

3 Configure Options

Optional configuration object:

MOS.init({ once: false, // two-way: repeat when scrolling up & down rootMargin: "-50px 0px -50px 0px" });
